# Agent Instructions

## Running the app

- This is a Next.js project.
- To start the development server, run: `npm run dev`.
- Open http://localhost:3000 in the browser.
- Do not assume other ports or commands unless the project changes.

## API endpoints

- Write tests for every endpoint you create, and always validate that the endpoints are working correctly.
- Whenever you create or modify an API endpoint, add or update automated tests for it.
- Cover successful behavior, input validation, and relevant error cases.
- Use the project's existing test framework and conventions.
- Do not consider an endpoint complete until the checks pass.

## General workflow

- Inspect the existing project structure and conventions before making changes.
- Prefer focused changes and avoid unrelated edits.
- Run the narrowest relevant checks after a change.
- Ask before adding new packages.
- Keep the README updated when features change.
- Do not commit or push to GitHub unless I ask.
